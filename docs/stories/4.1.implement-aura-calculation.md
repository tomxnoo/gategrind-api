# Story 4.1: Implement Aura Calculation

## 📋 Story Overview

**Epic**: 4 - The "Aura" Power Level System  
**Story ID**: 4.1  
**Title**: Implement Aura Calculation  
**Status**: Approved 📝  
**Priority**: High  
**Story Points**: 5  

## 🎯 User Story

**As a** system, **I want** to calculate and store a user's Aura score, **so that** there is a single metric for their overall power.

## ✅ Acceptance Criteria

1. **Database Field**: An aura field is added to the ascendants database model ✅ (Already implemented)
2. **Calculation Method**: A `calculate_and_update_aura` method is created in the ProgressionService ✅ (Partially implemented)
3. **Formula Implementation**: The method correctly applies the updated formula: `(Level * 100) + (STR*10 + END*10 + TECH*5) + (Nodes Unlocked * 25)`
4. **Real-time Updates**: The aura calculation is triggered automatically when contributing factors change
5. **Performance**: Aura calculation completes within 100ms for typical user profiles
6. **Data Integrity**: All aura updates are atomic and consistent with database transactions

## 🔧 Technical Requirements

### Current Implementation Status
- ✅ **Database Field**: `aura` field exists in `Ascendant` model with proper indexing
- ✅ **Service Method**: `_calculate_and_update_aura` method exists in `ProgressionService`
- ❌ **Formula Mismatch**: Current formula uses different multipliers than specified
- ❌ **Public Method**: No public `calculate_and_update_aura` method exposed
- ❌ **Integration**: Not integrated with all progression events

### Required Changes

#### 1. Formula Correction
**Current Formula** (in `ProgressionService._calculate_and_update_aura`):
```python
base_aura = user.level * 10
stat_bonus = (str_level + end_level + tech_level) * 5
skill_bonus = unlocked_skills_count * 15
```

**Required Formula** (per AC #3):
```python
base_aura = user.level * 100
stat_bonus = (str_level * 10) + (end_level * 10) + (tech_level * 5)
skill_bonus = unlocked_skills_count * 25
```

#### 2. Public Method Exposure
Create public `calculate_and_update_aura` method that can be called by other services and API endpoints.

#### 3. Integration Points
Ensure aura calculation is triggered by:
- Level progression (`add_xp` method)
- Stat rewards (`add_stat_rewards` method)
- Skill node unlocking (future Story 4.2)
- Quest completions (future integration)
