# Story 3.2: Implement Skill Tree Unlocking

## Status
**COMPLETED** ✅ - Core Functionality Complete, Movement Distribution Enhanced

## Story

**As a** user,  
**I want** to spend my earned Skill Points to unlock new nodes on the Skill Tree,  
**so that** I can master new movements and enhance my progression capabilities.

## ⚠️ CRITICAL PROGRESSION UPDATES

**New Progression Mechanics (Updated 2024-12-19)**:
1. **Ascendant Level Up**: Grants +1 to ALL 3 skill point types (STR, END, TECH)
2. **Skill Point Deduction**: Unlocking nodes DEDUCTS skill points (cumulative cost: 0+3+8+15+25 = 51 total per category)
3. **Stat Requirements**: Increased by 500 per level (0-500, 500-1000, 1000-1500, 1500-2000, 2000-2500)
4. **Skill Point Costs**: Level costs are 0, 3, 8, 15, 25 skill points respectively

**Movement Distribution Enhancement (Updated 2024-12-19)**:
5. **Multiple Movements Per Node**: Each skill tree node now provides 2-3 related movements instead of just 1
6. **Logical Grouping**: Movements are grouped by type and difficulty within each progression level
7. **Better Progression Pacing**: 165 substantial unlocks instead of 165 individual movements
8. **Total Movement Library**: Expanded from 165 to 702 total movements across all nodes
9. **Average Movements Per Node**: 4.3 movements per unlock for more rewarding progression

**Total Category Costs**:
- **UPPER_DYNAMIC**: 51 skill_points + 35 STR + 6 END + 10 TECH skill points
- **MOBILITY_FLOW**: 51 skill_points + 6 STR + 17 END + 28 TECH skill points  
- **PULL_VERTICAL**: 51 skill_points + 35 STR + 10 END + 6 TECH skill points

## Acceptance Criteria

1. **Skill Tree Endpoint**: A POST /v2/progression/unlock-skill endpoint is created that accepts a node_id parameter
2. **Requirement Verification**: The ProgressionService verifies the user meets all requirements for the skill node:
   - Ascendant Level requirement for the skill node
   - Required Stat Points (STR, END, TECH stat values) for the skill node
   - Required Skill Points (strength skill points, endurance skill points, technique skill points) for the skill node
   - Minimum Aura score requirement (if applicable)
   - Any prerequisite nodes that must be unlocked first
   - Quest completion requirements (if applicable)
   - Achievement requirements (if applicable)
3. **Configurable Requirements**: All skill node requirements (stat points, skill points, level, aura, prerequisites, quest completion, etc.) are stored in the database/configuration and easily modifiable without code changes
4. **User-Initiated Unlocking**: Users actively choose which skill node to unlock via API call; nodes do not unlock automatically when requirements are met
5. **Skill Point Deduction**: If requirements are met, the required Skill Points are deducted from the user's total only after successful unlock (skill point requirements set to 0 are skipped)
6. **Progress Tracking**: A new entry is created in the user_skill_progress table to track the unlocked skill
7. **Response Data**: The API response includes the user's updated Skill Point totals and new Aura score
8. **Error Handling**: Appropriate error responses for insufficient requirements, invalid node_id, or already unlocked skills
9. **Transaction Safety**: All database operations are wrapped in transactions to ensure data consistency

## Dev Notes

### Architecture Context
This story builds upon the stat milestone progression system (Story 3.1) and integrates with the existing skill tree content from the Content Bible (Story 1.2). The skill tree unlocking system is a core component of Epic 3's dual-path progression system.

### Technical Implementation Details

**API Endpoint**: 
- Route: POST /v2/progression/unlock-skill
- Request: `{"node_id": "skill_node_identifier"}`
- Response: Updated user progression data including skill points and aura

**Configurable Requirements System**:
- All skill node requirements stored in database table or JSON configuration files
- Comprehensive requirement types: stat points, skill points, level, aura, prerequisites, quests, achievements
- Example format: `{"push_up_node_1": {"strength_stat": 500, "endurance_stat": 300, "technique_stat": 100, "strength_skill_points": 3, "endurance_skill_points": 1, "technique_skill_points": 2, "level": 5, "aura": 50, "prerequisites": [], "quest_requirements": [], "achievement_requirements": []}}`
- Easy modification through admin interface or direct config file editing
- Hot-reloading of requirements without application restart
- Validation to ensure requirement changes don't break progression logic
- Maintains all existing verification logic while making thresholds configurable
- Skill point requirements set to 0 are skipped in both verification and deduction phases

**Service Integration**:
- Extends existing ProgressionService from Story 2.1
- Integrates with skill tree data seeded in Story 1.2
- Uses aura calculation service for updated scores
- Dynamic requirement loading and caching for performance

**Database Requirements**:
- user_skill_progress table for tracking unlocked skills
- skill_requirements table/config for storing configurable requirements
- Skill tree nodes data with dynamic requirement lookup
- Transaction safety for skill point deduction and progress tracking
