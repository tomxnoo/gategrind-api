# Story 5.2: dungeon-system

## Status
Draft

## Story
**As a** user,
**I want** to use my Shadow Keys to enter challenging dungeons with escalating difficulty levels,
**so that** I can earn exclusive rewards and test my progression against endgame content.

## Acceptance Criteria

### Entry System
- [ ] Users can enter any unlocked dungeon level for exactly 1 Shadow Key
- [ ] System validates user has sufficient aura, stats, and skill tree progression for the level
- [ ] Entry is blocked if user has an active session or insufficient requirements
- [ ] Levels unlock sequentially (must complete level N to unlock level N+1)
- [ ] No maximum level cap - infinite progression with scaling difficulty

### Progressive Scaling
- [ ] Aura requirements scale exponentially: Level 1: 100, Level 2: 150, Level 3: 225, etc. (1.5x multiplier)
- [ ] Stat requirements scale progressively: Level 1: 15 each stat, scaling by 1.5x per level
- [ ] Skill tree requirements increase with levels (Movement nodes required)
- [ ] Trial difficulty and complexity increase with level
- [ ] Rewards scale with level difficulty (better rewards for higher levels)

### Trial System
- [ ] Each dungeon generates 3-5 dynamic trials using QuestGenerationService
- [ ] Daily modifiers affect trial generation for variety
- [ ] Trials must be completed in sequence within the session
- [ ] Failed trials allow retry within the same session
- [ ] Session expires after 2 hours of inactivity

### Reward System
- [ ] Completion provides level-appropriate rewards (aura, items, achievements)
- [ ] Rewards scale exponentially with level difficulty
- [ ] Special milestone rewards at certain level thresholds (10, 25, 50, 100, etc.)
- [ ] Failed sessions provide partial rewards based on trials completed

### Integration Requirements
- [ ] API endpoints provide immediate responses for Discord bot integration
- [ ] System integrates with existing Shadow Key economy
- [ ] Progress tracking updates user statistics and achievements
- [ ] Session recovery handles disconnections and timeouts gracefully

## Key Features
1. **Shadow Key Economy**: Each dungeon level requires exactly 1 Shadow Key for entry (consistent cost)
2. **Infinite Level Progression**: Unlimited dungeon levels with exponentially scaling difficulty and requirements
3. **Progressive Requirements**: Each level requires higher aura, stats (STR/END/TECH), and skill tree progression
4. **Entry Validation**: Comprehensive checks for aura, stats, skill tree nodes, and level unlock status
5. **Trial Generation**: Dynamic trials using QuestGenerationService with daily modifiers for variety
6. **Async Discord Support**: API provides immediate responses with session tracking for Discord bot integration
7. **Reward Distribution**: Completed dungeons provide Shadow Essence and exclusive rewards scaled by level difficulty
8. **Progress Tracking**: System tracks completion history, unlocked levels, and performance statistics
9. **Session Recovery**: Users can recover interrupted sessions with proper state restoration and timeout handling
10. **Skill Tree Integration**: Progressive movement node requirements that scale with dungeon level
11. **Balanced Economy**: Aura and stat requirements scale progressively to match 3 daily Shadow Keys

### 4. DungeonService Implementation
- [ ] **Create DungeonService class extending BaseService**
  ```python
  class DungeonService(BaseService):
      """Service for managing dungeon entry, progression, and completion."""
      
      async def enter_dungeon(self, ascendant_id: int, dungeon_level: int) -> Dict[str, Any]:
          """Enter a dungeon level with validation and trial generation."""
          # Always costs 1 Shadow Key regardless of level
          shadow_key_cost = 1
          
          # Validate entry requirements
          await self.validate_entry_requirements(ascendant_id, dungeon_level)
          
          # Deduct Shadow Keys
          await self.deduct_shadow_keys(ascendant_id, shadow_key_cost)
          
          # Generate trials for the level
          trials = await self.generate_trials(dungeon_level)
          
          # Create session
          session = await self.create_session(ascendant_id, dungeon_level, trials, shadow_key_cost)
          
          return {
              "session_id": session.id,
              "level": dungeon_level,
              "trials": trials,
              "expires_at": session.expires_at
          }
      
      async def validate_entry_requirements(self, ascendant_id: int, dungeon_level: int) -> bool:
          """Validate Aura, Shadow Keys, and skill tree requirements with infinite scaling"""
          user_stats = await self.get_user_stats(ascendant_id)
          
          # Calculate progressive requirements
          required_aura = self.calculate_aura_requirement(dungeon_level)
          required_stats = self.calculate_stat_requirements(dungeon_level)
          required_skill_nodes = self.calculate_skill_tree_requirements(dungeon_level)
          
          # Check if user has unlocked this level
          highest_unlocked = await self.get_highest_unlocked_level(ascendant_id)
          if dungeon_level > highest_unlocked:
              raise DungeonLevelLockedError(f"Level {dungeon_level} is locked. Complete level {highest_unlocked} first.")
          
          # Validate requirements
          if user_stats.aura < required_aura:
              raise InsufficientRequirementsError(f"Requires {required_aura} aura (you have {user_stats.aura})")
          
          return True
      
      def calculate_aura_requirement(self, level: int) -> int:
          """Calculate aura requirement with exponential scaling (1.5x multiplier)."""
          base_aura = 100
          return int(base_aura * (1.5 ** (level - 1)))
      
      def calculate_stat_requirements(self, level: int) -> dict:
          """Calculate stat requirements with progressive scaling."""
          base_stat = 10
          multiplier = 1.5
          required_value = int(base_stat * (multiplier ** (level - 1)))
          
          return {
              'strength': required_value,
              'endurance': required_value,
              'technique': required_value
          }
      
      def calculate_skill_tree_requirements(self, level: int) -> int:
          """Calculate required Movement skill tree nodes for infinite progression."""
          if level <= 1:
              return 0
          elif level <= 5:
              return level - 1
          elif level <= 10:
              return 5 + (level - 5) * 2
          else:
              return 15 + (level - 10) * 3
          
      async def deduct_shadow_keys(self, ascendant_id: int, amount: int = 1) -> bool:
          """Deduct Shadow Keys with transaction safety (always 1 for dungeons)"""
          
      async def generate_trials(self, dungeon_level: int, daily_modifier: Optional[DailyModifier] = None) -> List[Dict[str, Any]]:
          """Generate movement trials with difficulty scaling for infinite levels"""
          # Base number of trials with scaling
          base_trials = 3
          additional_trials = min(2, dungeon_level // 5)  # +1 trial every 5 levels, max 5 total
          total_trials = base_trials + additional_trials
          
          # Generate trials with increasing difficulty
          trials = []
          for i in range(total_trials):
              trial_difficulty = self.calculate_trial_difficulty(dungeon_level, i)
              trial = await self.quest_generation_service.generate_trial(
                  difficulty=trial_difficulty,
                  level=dungeon_level,
                  trial_index=i,
                  daily_modifier=daily_modifier
              )
              trials.append(trial)
          
          return trials
      
      def calculate_trial_difficulty(self, level: int, trial_index: int) -> float:
          """Calculate trial difficulty based on level and position."""
          base_difficulty = 0.5 + (level * 0.1)  # Increases with level
          trial_modifier = trial_index * 0.1  # Later trials are harder
          return min(1.0, base_difficulty + trial_modifier)
          
      async def complete_trial(self, trial_id: int, progress_data: Dict[str, Any]) -> Dict[str, Any]:
          """Complete a trial and check session completion"""
          
      async def calculate_rewards(self, session: DungeonSession) -> List[Dict[str, Any]]:
          """Calculate and distribute rewards with exponential scaling"""
          level = session.dungeon_level
          base_aura = 50
          
          # Exponential reward scaling
          aura_reward = int(base_aura * (1.3 ** (level - 1)))
          
          rewards = [
              {
                  'type': 'aura',
                  'amount': aura_reward,
                  'description': f'Dungeon Level {level} Completion Bonus'
              },
              {
                  'type': 'shadow_essence',
                  'amount': level * 5,
                  'description': f'Shadow Essence from Level {level}'
              }
          ]
          
          # Milestone rewards
          if level % 10 == 0:  # Every 10 levels
              rewards.append({
                  'type': 'special_item',
                  'item_id': f'dungeon_milestone_{level}',
                  'description': f'Level {level} Milestone Achievement'
              })
          
          return rewards
          
      async def cleanup_expired_sessions(self) -> int:
          """Clean up expired sessions (background task)"""
  ```

### Dungeon Level Design & Progression System
Based on epic requirements, the dungeon system provides:

**Level Progression & Unlocking:**
1. **Sequential Unlocking**: Users must complete current level to unlock the next level
2. **Level Selection**: Users can choose any previously unlocked level to replay
3. **Progressive Difficulty**: Each level has higher stat/aura requirements and harder trials
4. **Completion Tracking**: System tracks highest completed level per user

**Level Requirements (Infinite Progression - 1 Shadow Key per level):**
- **Level 1**: No requirements (tutorial level) - 1 Shadow Key
- **Level 2**: Complete Level 1 + Aura ≥ 150 + Movement I node unlocked - 1 Shadow Key
- **Level 3**: Complete Level 2 + Aura ≥ 225 + STR ≥ 15 + Movement II node unlocked - 1 Shadow Key
- **Level 4**: Complete Level 3 + Aura ≥ 338 + STR ≥ 23 + END ≥ 15 + Movement III node unlocked - 1 Shadow Key
- **Level 5**: Complete Level 4 + Aura ≥ 507 + STR ≥ 34 + END ≥ 23 + TECH ≥ 15 + Movement IV node unlocked - 1 Shadow Key
- **Level 6+**: Exponential scaling continues infinitely (Aura × 1.5, Stats × 1.5 per level) - 1 Shadow Key each

**Trial Difficulty Scaling:**
1. **Reps Scaling**: Base reps × level multiplier (1.2^level)
2. **Time Pressure**: Shorter completion windows at higher levels
3. **Movement Complexity**: Advanced movements unlock at higher levels
4. **Trial Count**: More trials per dungeon at higher levels (3 + level/2)
5. **Modifier Intensity**: Stronger daily modifiers at higher levels

**Reward Scaling:**
- **Aura Rewards**: Exponential scaling (50 × 1.3^(level-1)) = 50, 65, 85, 110, 143...
- **Shadow Essence**: Primary mystical currency (level × 5 base amount)
- **Stat Rewards**: Bonus stat points scale with level (level × 2 points distributed across STR/END/TECH)
- **Milestone Rewards**: Special rewards every 10 levels (exclusive items, achievements)

### Daily Modifier System
The modifier system provides variety and replayability:
1. **Daily Rotation**: Modifiers change daily to keep content fresh
2. **Trial Enhancement**: Modifiers affect trial generation and difficulty
3. **Reward Bonuses**: Some modifiers provide additional reward opportunities
4. **Difficulty Scaling**: Modifiers can increase or decrease challenge level
5. **Variety Types**: Movement focus, time pressure, rep multipliers, etc.
