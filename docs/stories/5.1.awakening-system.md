# Story 5.1: awakening-system

## Status
Draft

## Story
**As a** user,
**I want** to complete daily Awakening challenges that provide meaningful progression rewards,
**so that** I have engaging daily content that helps me progress in the game.

## Acceptance Criteria
1. Users can access a daily Awakening challenge that generates multiple quests (minimum of 3, but could be more)
2. Awakening challenges are personalized based on the user's current progression level and unlocked skills
3. Completing Awakening quests rewards the user with XP, stat points, and Shadow Keys for dungeon access
4. Users can manually reset their Awakening once per day to get new quests at a lower difficulty tier
5. When reset, completed quests remain completed and are excluded from the new quest generation pool
6. Users can view their Awakening progress and completion status through the Discord interface
7. The system tracks Awakening completion streaks and provides bonus rewards for consecutive completions

### Challenge Generation Algorithm
Based on epic requirements, the awakening system should generate:
1. **Multiple Quests**: Typically 3 quests per daily awakening session
2. **Personalized**: Use user's unlocked skills and current progression level
3. **Varied**: Different quest types (reps, time, specific movements)
4. **Progressive**: Difficulty scales with user advancement
5. **Achievable**: Realistic goals that encourage daily engagement

### Manual Reset System
The reset functionality provides strategic depth:
1. **Once Per Day**: Users can reset their awakening session once daily
2. **Tier Reduction**: Reset quests are generated at a lower difficulty tier
3. **Preserve Progress**: Completed quests remain completed and are excluded
4. **Strategic Choice**: Trade difficulty for lower rewards
5. **Exclusion Logic**: New quest generation excludes completed quest types/movements
