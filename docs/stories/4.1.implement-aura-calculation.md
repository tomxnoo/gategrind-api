### Aura Calculation Formula
```
Aura = (Level * 100) + (STR*10 + END*10 + TECH*5) + (Nodes Unlocked * 25)
```

**Components**:
- **Base Level**: `user.level * 100`
- **Stat Levels**: `(stats.str_level * 10) + (stats.end_level * 10) + (stats.tech_level * 5)`
- **Skill Progress**: `unlocked_nodes_count * 25`
