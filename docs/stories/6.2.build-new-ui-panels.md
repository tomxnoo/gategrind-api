# Story 6.2: Build New UI Panels

## Status
Draft

## Story
**As a** Discord bot user,
**I want** new UI panels for V2 features (Profile V2, Skill Tree, and Dungeon flows) while maintaining the enhanced Awakening panel,
**so that** I can access and interact with the enhanced V2 backend functionality through the familiar Discord interface patterns.

## Acceptance Criteria
1. Create a new Profile V2 panel that displays comprehensive V2 profile data including ascendant stats, skill progress, dungeon progress, and awakening information using V2 endpoints
2. Build a Skill Tree panel that shows the movement library structure with categories, allows users to view unlocked skills, and displays progression paths
3. Maintain the existing enhanced Awakening panel (already using V2 endpoints) with its current functionality and UI patterns
4. Develop a Dungeon panel that displays available dungeons, user progress, shadow key balance, and provides dungeon entry/trial functionality
5. All panels must follow V1 UI patterns: @register decorator, render_embed() and build_view() methods, consistent ANSI formatting
6. Views must add EphemeralPanelSelect as first item, use timeout=300, validate user with interaction.user.id checks
7. All button callbacks must use run_with_animation() helper for consistent loading behavior
8. Implement comprehensive error handling with fallback embeds when API is unavailable

### V2 API Integration Details
- **Profile API**: `/v2/users/me/profile` returns `AscendantProfileResponse` with stats, skills, dungeons
- **Movements API**: `/v2/movements/library` returns category-based movement structure
- **Awakening API**: Already integrated in awakening_panel.py - no changes needed
- **Dungeons API**: 
  - `/v2/dungeons/` - List available dungeons
  - `/v2/dungeons/enter` - Enter a dungeon
  - `/v2/dungeons/complete-trial` - Complete dungeon trial
  - `/v2/dungeons/session` - Get active session

### V1 UI Patterns to Follow
- **Panel Class Structure**:
  ```python
  @register
  class PanelName:
      key = "panel_key"
      label = "Panel Label"
      emoji = "🎯"
      
      @staticmethod
      async def render_embed(bot, user, **kwargs) -> discord.Embed:
          # Build ANSI formatted embed
      
      @staticmethod
      async def build_view(bot, user, **kwargs) -> discord.ui.View:
          # Return view with EphemeralPanelSelect + buttons
  ```
- **ANSI Embed Format**: Use code blocks with ANSI color codes for consistent styling
- **Button Callbacks**: Always use `await run_with_animation(interaction, work_function)`
- **Error Handling**: Try/except with fallback embeds, use `handle_panel_errors` decorator

### Discord UI Implementation Details
- **View Structure**: `class MyView(discord.ui.View):` with `super().__init__(timeout=300)`
- **User Validation**: Every button callback checks `if interaction.user.id != self.view.user.id:`
- **Loading Pattern**: Defer interaction, run work function, return (embed, view) tuple
- **Panel Colors**: Profile (#9146FF purple), Awakening (varies), Log Reps (#00FF7F green)
- **Header Pattern**: Always include `get_system_status_header(user)` and `get_panel_sub_header("key")`

        await run_with_animation(interaction, self._do_work)
